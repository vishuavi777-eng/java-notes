# Learning New Technology

## Question

How do you learn a new technology?

## Main Answer

When I learn a new technology, I first try to understand why it is used and what problem it solves. Then I learn the basics, build a small practical project, and connect it with my previous experience.

For example, I am currently improving my Java backend and Spring Boot skills. I started by learning REST APIs, controller-service-repository layers, DTOs, validation, exception handling, Spring Data JPA, and MySQL integration. Then I built an Employee Task / Call Allocation System to practice these concepts.

I learn better when I build something practical. I also write notes, revise interview questions, and compare new concepts with systems I have already worked on, like diet automation and call allocation.

## Key Points to Remember

- Understand the purpose first.
- Learn basics.
- Build practical project.
- Write notes.
- Connect with previous experience.
- Keep improving step by step.

## Short Version

I learn new technology by understanding the purpose, learning basics, building a small practical project, and writing notes. For Spring Boot, I built an Employee Task / Call Allocation System to practice APIs, layers, DTOs, JPA, validation, and exception handling.

This answer is useful for explaining your current Java/Spring Boot preparation honestly.
