# Why Are You Looking for a Job Change?

## Question

Why are you looking for a job change?

## Main Answer

I am looking for a job change because I want to work more in Java backend and modern backend technologies like Spring Boot.

In my previous experience, I worked on many real business systems related to healthcare and automation, where I gained strong experience in business logic, APIs, databases, and system development.

Now I want to move toward more structured backend development, scalable systems, and modern Java technologies. I am continuously improving my skills in Spring Boot, REST APIs, and backend architecture.

I believe changing to a new role will help me get better technical exposure, work on larger backend systems, and continue growing as a Java Full Stack / Backend Developer.

## Short Version

I am looking for a job change mainly to grow more in Java backend and Spring Boot development. I already have strong experience in backend logic, APIs, and automation systems, and now I want to work on modern backend technologies and scalable applications.

## Key Points to Remember

- Keep it positive.
- Focus on growth.
- Mention Java and backend direction.
- Do not criticize previous company.
- Connect past experience with future role.
