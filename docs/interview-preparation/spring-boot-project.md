# Explain Your Spring Boot Project

## Question

Explain your Spring Boot project.

## Main Answer

My recent project is an Employee Task / Call Allocation System developed using Java and Spring Boot.

The purpose of this system is to manage employees, tasks, and call assignments efficiently. In this project, admin can create employees, create tasks or calls, assign them to employees, and track task status.

I used Spring Boot REST APIs for backend development and followed layered architecture. The controller layer handles API requests, the service layer manages business logic, and the repository layer handles database operations using Spring Data JPA.

I also used DTOs for request and response handling, entity classes for database mapping, and global exception handling for better API responses.

The project helped me work on backend architecture, API development, CRUD operations, database integration, and clean code structure. I also focused on proper separation of layers and reusable business logic.

Technologies used in this project include Java, Spring Boot, Spring Data JPA, MySQL, REST APIs, and Maven.

## Project Flow

- Admin creates employees in the system.
- Admin creates tasks or call records.
- Admin assigns tasks or calls to employees.
- Employee task status is tracked in the system.
- Controller layer receives API requests.
- Service layer handles business logic and validation.
- Repository layer performs database operations using Spring Data JPA.
- API returns proper response using DTOs and exception handling.
