# Roles and Responsibilities

## Question

What are your roles and responsibilities?

## Main Answer

In my previous projects, my main responsibilities included backend development, business logic implementation, database handling, and automation system development.

I worked closely with business teams and dietitians to understand requirements and convert them into technical solutions. One of my main areas was the Diet Engine system, where I implemented logic for personalized meal plans, food rules, quantity management, and dynamic diet generation.

I also developed backend APIs and handled database design using MySQL. I worked on data flow between mobile apps, backend systems, and admin dashboards.

Apart from backend work, I also worked on Android and iOS application features, API integration, bug fixing, and performance improvements.

Another important responsibility was automation development. I created customer support call automation systems that automatically scheduled and assigned calls like weight check calls, motivation calls, and follow-up calls. This reduced manual work and improved team productivity.

I was also responsible for maintaining existing modules, enhancing features, solving production issues, and improving system stability.

Recently, I started focusing more on Java backend development and Spring Boot. To improve my backend architecture understanding, I created a Spring Boot project using controller, service, and repository layers along with REST APIs and DTOs.
