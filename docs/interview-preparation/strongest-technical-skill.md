# Strongest Technical Skill

## Question

What is your strongest technical skill?

## Main Answer

I think my strongest technical skill is backend business logic and automation system development.

In my previous projects, I worked a lot on creating systems that solved real business problems through automation. One of the main examples is the Diet Engine system, where I implemented complex logic for personalized diet plan generation based on user goals, food preferences, restrictions, and eating patterns.

I also developed automation systems for customer support call allocation, where calls were automatically scheduled and assigned based on different conditions. This helped reduce manual work and improve productivity.

Apart from automation logic, I am also comfortable with backend APIs, database design, and handling data flow between mobile apps, backend systems, and admin panels.

I enjoy understanding business requirements and converting them into scalable technical solutions. Recently, I have been focusing more on Java backend development and improving my skills in Spring Boot and backend architecture.
