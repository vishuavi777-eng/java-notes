# Interview Practice Mode

<span data-hide-page-complete="true"></span>

Use this page for active interview practice. Select a skill and level, pick a random question, answer it out loud, then reveal the answer.

<div id="interview-practice-app"></div>

## How to Practice

1. Select one skill and one level.
2. Click **Random Question**.
3. Speak your answer before opening the answer.
4. Click **Show Answer** and compare.
5. Mark confidence honestly: Red, Yellow, or Green.
6. Use **Weak Only** before interviews.

## Confidence Meaning

- **Red**: I cannot answer this yet.
- **Yellow**: I know the idea, but need revision.
- **Green**: I can answer this clearly in interview.
