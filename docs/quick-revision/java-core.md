# Java Core Quick Revision

## Must Know

- JVM loads, verifies, and executes Java bytecode.
- JRE runs Java applications.
- JDK includes tools for development.
- Java is platform independent because bytecode runs on JVM.

## OOP

- Encapsulation: hide data using classes and access methods.
- Inheritance: reuse behavior from parent class.
- Polymorphism: same method call behaves differently.
- Abstraction: hide implementation details.

## String

- `String` is immutable.
- String literals are stored in String pool.
- `StringBuilder` is mutable and not thread-safe.
- `StringBuffer` is mutable and synchronized.

## Collections

- `ArrayList`: dynamic array, fast random access.
- `LinkedList`: node-based, fast insert/delete at known node.
- `HashMap`: key-value storage, uses hashing.
- `HashSet`: unique values, backed by HashMap.

## Multithreading

- `synchronized` protects critical section.
- `volatile` gives visibility, not atomicity.
- `ExecutorService` manages thread pools.
- Deadlock happens when threads wait for each other forever.

## Interview Tip

For Java answers, explain concept, internal working, trap, and one example.
