# Behavioral Interview Quick Revision

## Answer Formula

```text
Situation -> Action -> Result -> Learning
```

## Strengths

- Practical problem solving.
- Ownership of complete flow.
- Business requirement understanding.
- Backend logic and automation thinking.

## Weakness

- Earlier focused more on fast delivery than documentation.
- Improved by writing notes, breaking logic into smaller parts, and focusing on clean architecture.

## Conflict

- Avoid blaming.
- Understand requirement.
- Explain technical impact.
- Agree on practical solution.

## Production Issue

- Understand issue clearly.
- Check logs, database, API response, and recent changes.
- Fix urgent issue first.
- Find root cause.
- Verify after fix.

## Tight Deadline

- Prioritize core flow.
- Break work into smaller tasks.
- Communicate risks clearly.
- Deliver practical solution.

## Ownership

- Use customer support call automation example.
- Mention requirement understanding, backend logic, database flow, and business impact.
