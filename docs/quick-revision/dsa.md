# DSA Quick Revision

## Complexity

- `O(1)`: constant.
- `O(log n)`: binary search.
- `O(n)`: single loop.
- `O(n log n)`: efficient sorting.
- `O(n^2)`: nested loops.

## Arrays and Strings

- Use two pointers for reverse, palindrome, sorted pair problems.
- Use sliding window for subarray and substring problems.
- Use hashing for frequency and lookup.

## Linked List

- Use slow and fast pointers for middle and cycle.
- Reverse list using previous, current, next.
- Be careful with null checks.

## Stack and Queue

- Stack: last in, first out.
- Queue: first in, first out.
- Stack solves parentheses and next greater element.

## Trees

- DFS uses recursion or stack.
- BFS uses queue.
- Inorder for BST gives sorted order.
- Height/depth uses recursion.

## Interview Tip

Always explain brute force first if needed, then optimize with pattern.
